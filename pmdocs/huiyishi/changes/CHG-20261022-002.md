## 变更内容

### 高优先级修改（已实施）

1. **解决认证需求矛盾**
   - 删除FR-012 JWT认证（包括token、refresh token机制）
   - 删除NFR-014 JWT认证相关内容
   - 改为FR-014用户身份验证（用户只能操作自己的预订）

2. **调整HTTPS验收标准**
   - 删除FR-011 HTTPS访问
   - 改为FR-012安全访问
   - 移除SSL Labs测试、HSTS头部等具体技术实现
   - 改为"系统通过安全协议访问，浏览器显示安全标识"
   - 同步修改NFR-013

3. **修复用户名管理问题**
   - 新增FR-010用户白名单管理
   - 管理员能够添加/删除用户白名单
   - 用户预订时只能从白名单中选择用户名
   - 白名单为空时允许任意用户名输入（临时方案）
   - 同步修改5.1明确不做"用户认证系统（使用简单用户名白名单）"

4. **修复会议主题显示问题**
   - 修改FR-008查看我的预订：会议主题（用户本人查看时解密显示）
   - 修改FR-011数据加密：用户本人查看自己的预订时，会议主题和参会人解密显示
   - 明确加密范围：仅数据库存储加密，前端显示解密

5. **调整并发要求**
   - 将并发要求从300人降到50人
   - 修改1.2目标：支持50人同时使用
   - 修改1.3成功度量：支持50人同时使用
   - 修改NFR-001：50人并发
   - 修改验收标准表：50人并发

### 功能编号调整
- 原FR-010数据加密 → FR-011数据加密
- 原FR-011 HTTPS访问 → FR-012安全访问
- 原FR-012 JWT认证 → 已删除
- 新增FR-010用户白名单管理
